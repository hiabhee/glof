# GlacierLens

**GlacierLens** is an evidence-first web explorer for studying Himalayan glacier retreat, glacial-lake evolution, and Glacial Lake Outburst Flood (GLOF) hazards.

The first proof of concept focuses on **South Lhonak Lake and South Lhonak Glacier, North Sikkim, India**. It tells a defensible retrospective story across **2016 to the latest verified 2026 observation**: glacier retreat and lake growth, the October 2023 outburst, and the terrain and downstream context that made the event consequential.

This is a research visualisation and hazard-screening tool. It is **not** an operational early-warning system or a deterministic GLOF prediction service.

## Success criterion for the POC

A reviewer can select South Lhonak Lake, move through a curated timeline, visibly relate the lake to South Lhonak Glacier, inspect measured change, compare imagery from before and after October 2023, and understand every input behind the hazard-context display.
