# Final-five data intake register

This register is the admission gate for the final five lake–glacier systems. It is intentionally conservative: an empty field means the application must not present that layer as available.

## Approval rule

A site becomes `evidence-ready` only when all four asset groups are present, cited, seasonally comparable, and manually reviewed. Until then, the UI must show an unavailable/intake state and must not reuse South Lhonak imagery.
